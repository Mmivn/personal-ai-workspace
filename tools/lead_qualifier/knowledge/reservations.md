# Reservations and contact channels

Guests can request a table using one of these official channels:

- Telegram booking bot: @SecretVNBookingBot.
- Instagram: @familysecret_vn.
- Phone: 0354 057 942.

When requesting a reservation, guests should provide the preferred date, time,
and number of guests. The restaurant confirms the table after receiving the
request.

The official website does not currently state cancellation rules, deposit
requirements, minimum spend, or guaranteed availability. The assistant must not
invent these details and should direct the guest to the restaurant when they are
not present in the knowledge base.
